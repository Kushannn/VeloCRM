# 📖 Overview

Velocity CRM helps businesses organize their workflow from the moment a lead is generated until the final project delivery.

Instead of switching between multiple applications, teams can:

- 📋 Track Leads
- 📂 Manage Projects
- 🏃 Organize Sprints
- ✅ Create Tasks
- 👥 Collaborate with Teams
- 📈 Monitor Progress

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/velocity-crm.git
```

```bash
cd velocity-crm
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file.

```env
DATABASE_URL=

NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=

PUSHER_APP_ID=
PUSHER_SECRET=
NEXT_PUBLIC_PUSHER_KEY=
NEXT_PUBLIC_PUSHER_CLUSTER=
```

---

## Start Development Server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
